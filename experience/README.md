# 沉浸式互动体验整合区

本目录用于将 False Earth 的 3D 场景代码作为源码依赖整合进本项目，不使用 iframe，也不以截图代替场景。

- 上游项目： https://github.com/momentchan/false-earth
- 固定上游版本：`468a0cfd71698400103198a8eb91d5176fe4f59e`
- 上游代码许可证：MIT（保留上游 LICENSE 与版权声明）。
- 上游角色模型与贴图不作为本项目可再分发素材。尤其不加载 `public/models/Astronaut.glb` 及其配套宇航员贴图。
- 本项目将以自制/另行授权的儿童角色替换上游角色，并保留可复用的地形、草地、花朵、天空、光照、镜头与输入控制逻辑。
